# 云服务器方案（以后从这台电脑迁上去）

> 价格来自 2026 年 10 月搜到的第三方汇总文章，**不是官网报价**，活动经常变；下单前以官网为准，重点看**续费价**。

## 推荐配置

**2 核 4G、Linux（Ubuntu 22.04/24.04 或 Debian 12）、带宽 ≥ 3M。**
NapCat 内嵌了一个 QQ 客户端，单它就要吃 500MB–1GB 内存；再加上 AstrBot 和记忆插件，2G 内存会很紧。
国内机房只要不对外开网站，就不需要备案：面板通过 SSH 隧道在自己电脑上访问即可。

## 三家对比

| 方案 | 参考价（新用户，2 核 4G） | 优点 | 注意 |
|---|---|---|---|
| 腾讯云 轻量应用服务器 | 约 188–199 元/年 | 和 QQ 同一家，IP 段被风控的概率可能更低（未证实） | 部分低价限新用户首购，续费价会回升 |
| 阿里云 轻量应用服务器 | 活动 199 元/年；日常约 379 元/年 | 文档多、面板好用 | 活动价和日常价差得很大 |
| 华为云 Flexus 云服务器 X | 没查到可靠的 2026 年报价 | 新用户活动通常也有 | 自己去官网核价 |

要更便宜的话，也可以用 2 核 2G（38 元/年档）加 2G swap 硬撑，但长期记忆的向量检索会卡。

## 迁移步骤（概要，到时候我们再细化）

1. 服务器装 Docker，用 `deploy/docker-compose.yml` 起 AstrBot + NapCat；
2. 把本机 AstrBot 的 `data/` 整个拷上去（人设、模型配置、记忆都在里面）；
3. 在本机关掉 NapCat，再在服务器上扫码登录小号。**同一个号别两边同时挂着。**
4. 时区设成 `Asia/Shanghai`，否则定时任务的时间会错。

## 风险

- 小号换到机房 IP 登录，可能触发异地登录验证。第一次登录要在手机上确认，之后尽量别频繁换地方。
- 服务器的 6185（AstrBot 面板）和 6099（NapCat 面板）端口**不要对公网开放**，用 SSH 隧道访问：
  `ssh -L 6185:127.0.0.1:6185 -L 6099:127.0.0.1:6099 用户名@服务器IP`
